# 给小犹太将军的专属小网页 🎀

可爱梦幻风格的静态网页，送给星星女士的小礼物。纯 HTML + CSS + JavaScript，无需任何依赖。

## 使用方式

直接双击 `index.html` 即可在浏览器中打开。

## 页面板块

### 🏠 首页
- 在一起天数计数器（可在 `script.js` 顶部修改 `START_DATE`）
- 专属昵称卡片（4 张）
- 星星相册照片墙（点击照片可放大预览，支持左右键切换）
- 今日夸夸按钮（内置 22 条随机夸奖）
- 温柔留言卡片

### 💌 悄悄话
- 信封情书 — 点击信封展开一封温柔的信
- 纸条墙 — 6 张可爱便签，不同颜色和倾斜角度

### 🎮 小互动
- 默契大考验 — 3 道关于她的选择题，答完显示成绩
- 心情日记 — 点击表情记录心情，自动保存到浏览器（localStorage）
- 许愿瓶 — 输入愿望放进瓶子，瓶内星星会变多，数据本地存储

### 💝 惊喜盒
- 拆礼物 — 点击礼物盒，掉落 50 颗星星雨 + 显示特别留言
- 幸运签 — 点击抽取一支可爱签文（大吉/中吉/小吉），带翻转动画

## 图片

将照片放入 `assets/images/` 目录，命名为 `photo1.jpg` ~ `photo9.jpg`：

```
assets/images/
  photo1.jpg  photo2.jpg  photo3.jpg
  photo4.jpg  photo5.jpg  photo6.jpg
  photo7.jpg  photo8.jpg  photo9.jpg
```

缺少的图片会自动隐藏，不会影响其他功能。

## 背景音乐（可选）

将 MP3 文件放入 `assets/audio/bgm.mp3`，点击右下角 🎵 按钮即可播放。不放置该文件也不会报错。

## 视觉效果

- 粉色渐变背景 + 漂浮云朵 + 星星动画
- 玻璃拟态（毛玻璃）卡片
- 鼠标点击任意空白处出现爱心/星星特效
- 照片悬停放大 + 光泽扫过效果
- 响应式布局（桌面/平板/手机）

## 技术栈

纯 HTML + CSS + JavaScript，不依赖任何框架或第三方库。
